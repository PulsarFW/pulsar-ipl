## Overview

Client-only interior loader (based on Bob_74's IPL work). Loads base-game IPL fixes plus GTA Online DLC interiors by category — apartments, offices, bunkers, clubhouses, casino/penthouse, nightclubs, garages, hangars, and more. Each interior is enabled by its own file under `gtav/`, `gta_online/`, and the `dlc_*/` folders, so unused interiors can be dropped without touching the loader itself.
